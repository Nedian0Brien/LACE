# S2 의미 골격-문장 복원 학습

S2는 [[concepts/lace/의미-골격|의미 골격]]에서 원문으로 되돌아가는 짧은 역방향 복원 학습이 가능한지 확인한 실험이다.

이 실험은 open-ended generation 성공을 주장하지 않는다. `t5-small`을 조건별로 짧게 미세조정하고, held-out 문장에서 teacher-forced loss와 [[concepts/lace/복원-평가지표-token-f1-rouge-l|복원 평가 지표 - Token F1과 ROUGE-L]]을 비교했다.

핵심 결과는 다음이다.

```text
attention_scaffold: Token F1 0.3830, ROUGE-L 0.3117
random_scaffold:    Token F1 0.2286, ROUGE-L 0.1789
```

따라서 S2는 의미 골격 + [[concepts/lace/위치-보조-구조|위치 보조 구조]]가 무작위 골격보다 더 좋은 복원 학습 문제를 만들었다는 제한된 증거를 제공한다.

주의점도 있다. `idf_scaffold`는 loss가 가장 낮았고, `position_prior_scaffold`는 keyword recall이 매우 높았다. 따라서 S2 결과는 attention scorer의 최종 우위가 아니라, 중요도 기반 의미 골격 계열이 무작위 골격보다 유리하다는 주장으로 해석해야 한다.
