# 개인 연구자용 스케일다운 실험 설계

> 본 문서는 [연구기획서.md](./연구기획서.md) §9의 현실 실행 버전이다. 목표는 SOTA 경쟁이 아니라, 개인 연구자가 작은 compute로 LACE의 핵심 가설을 먼저 검증하고, 유효 신호가 있을 때만 더 큰 실험으로 확장하는 것이다.

---

## 0. 기본 전략

Claude가 작성한 기존 protocol은 reviewer 방어용 최종 설계에 가깝다. 8x A100, 10B~30B tokens, 350M scale-matched baselines, MINE 기반 mutual information 추정, 3 seed 반복은 개인 연구자의 1차 실험으로는 실행 불가능하다.

따라서 본 연구는 다음 순서로 진행한다.

```text
작은 latent 실험
→ forward process 차이 검증
→ 최소 generation demo
→ 논문화 가능한 신호 확인
→ compute 확보 후 scale-up
```

핵심 원칙은 세 가지다.

1. **처음에는 LLM 전체를 재학습하지 않는다.**
2. **pretrained encoder/decoder는 최대한 frozen으로 두고, compression path와 reverse module만 학습한다.**
3. **처음 논문 기여는 절대 성능이 아니라 forward process의 inductive bias 검증으로 둔다.**

## 1. 개인 연구자 Compute 가정

### 1.1 1차 실험 가정

| 항목 | 현실 가정 |
|---|---|
| GPU | 1x consumer GPU 12~24GB, 또는 Colab/Kaggle/L4/A10 단일 GPU |
| 모델 | T5-small, BART-base, 또는 작은 custom Transformer |
| 학습 대상 | compression path + reverse expander 중심 |
| 데이터 | 5k~50k examples subset |
| sequence length | 128~256 tokens |
| 학습 시간 | 실험 1개당 수십 분~수 시간 |
| 저장공간 | 20~100GB |

### 1.2 후속 확장 가정

| 단계 | Compute | 목적 |
|---|---|---|
| Solo-0 | CPU/GPU notebook | latent shape, metric, pipeline 검증 |
| Solo-1 | 1x GPU | 핵심 가설의 최소 정량 검증 |
| Solo-2 | 1x A100/L4 rented | 더 큰 subset, 더 안정적인 비교 |
| Lab-scale | 4~8x A100 | 논문 최종 비교, scale-matched baseline |

이 문서의 주 대상은 **Solo-0 ~ Solo-2**다.

## 2. 스케일다운 연구 질문

최종 연구 질문은 다음과 같다.

> 언어 diffusion에서 forward time을 random corruption이 아니라 information compression으로 정의하면 의미 보존에 유리한가?

개인 연구자용 1차 질문은 더 작게 자른다.

> 동일한 frozen text encoder latent에서, Gaussian noise나 random mask보다 learned compression path가 semantic reconstruction을 더 잘 보존하는가?

즉, 1차 연구는 거대한 language model 학습이 아니라 **latent trajectory 실험**이다.

---

## 3. 최소 모델 설계

### 3.1 Frozen Encoder

처음에는 encoder를 학습하지 않는다.

```text
x
→ pretrained encoder
→ h0 ∈ R^{N × d}
```

후보:

| Encoder | 장점 | 비고 |
|---|---|---|
| T5-small encoder | 가볍고 encoder-decoder 구조와 잘 맞음 | 1차 기본값 |
| BART-base encoder | denoising autoencoder 계열과 연결 쉬움 | GPU 여유 있을 때 |
| MiniLM/SentenceTransformer | semantic embedding 평가와 연결 쉬움 | token-level latent가 약할 수 있음 |

기본값은 **T5-small encoder frozen**이다.

### 3.2 Compression Path

처음에는 가장 단순한 3-level compression path만 사용한다.

```text
h0: 128 × d
z1: 64 × d
z2: 32 × d
z3: 16 × d
```

압축 모듈은 다음 순서로 구현한다.

| 버전 | 방식 | 목적 |
|---|---|---|
| C0 | average pooling | 하한선 |
| C1 | attention pooling with learned queries | 기본 제안 |
| C2 | attention pooling + semantic regularization | full small model |

VQ, variational bottleneck, low-rank bottleneck은 1차 범위에서 제외한다.

### 3.3 Reverse Expander

각 단계에서 더 상세한 latent를 복원한다.

```text
z3 → z2
z2 → z1
z1 → h0
```

처음에는 shallow Transformer 또는 cross-attention block을 사용한다.

```text
L_stage = Σ_t d(Expand_t(z_t), z_{t-1})
```

거리 함수 기본값:

| Loss | 용도 |
|---|---|
| MSE | latent reconstruction |
| cosine distance | 방향성 보존 |
| optional InfoNCE | collapse 방지 |

### 3.4 Renderer

초기 실험에서 renderer는 두 단계로 나눈다.

| 단계 | Renderer | 이유 |
|---|---|---|
| Phase 1~2 | 없음 | latent 복원과 forward process 비교를 먼저 검증 |
| Phase 3 | frozen T5 decoder 또는 small adapter decoder | 텍스트 복원 demo |

중요한 점: 처음부터 좋은 텍스트 생성을 목표로 두면 실험이 너무 커진다. 먼저 **압축 latent가 의미를 보존하는지** 확인한다.

## 4. 단계형 실험 계획

## Phase 0. Pipeline Sanity Check

**목표**: 학습 전에 데이터, encoder latent, shape, metric pipeline이 정상 동작하는지 확인한다.

| 항목 | 설정 |
|---|---|
| 데이터 | WikiText-2 또는 XSum 1k examples |
| 모델 | T5-small encoder frozen |
| 학습 | 없음 |
| 출력 | h0 shape, pooling shape, baseline MSE/cosine |

**통과 조건**:

- 입력 문장이 고정 길이 latent로 안정적으로 변환된다.
- z1/z2/z3 shape가 기대대로 줄어든다.
- pooling-only reconstruction의 MSE/cosine이 측정된다.

**실패 시**:

- sequence length를 128로 줄인다.
- batch size를 1~4로 줄인다.
- T5-small 대신 더 작은 encoder를 사용한다.

---

## Phase 1. Latent Compression Proof

**목표**: compression path가 h0를 단계적으로 압축하고 복원할 수 있는지 확인한다.

| 항목 | 설정 |
|---|---|
| 데이터 | WikiText-2 또는 XSum 5k~10k examples |
| 모델 | frozen encoder + C1 compression path + reverse expander |
| 학습 대상 | compressor, expander |
| sequence length | 128 |
| batch size | GPU에 맞게 4~32 |
| epoch | 3~10 |

**측정 지표**:

| 지표 | 해석 |
|---|---|
| h0 reconstruction MSE | 낮을수록 복원 가능 |
| h0 cosine similarity | 높을수록 latent 방향 보존 |
| z_t stage별 MSE | 압축이 강해질수록 증가해야 함 |
| latent perturbation sensitivity | decoder가 latent를 실제로 쓰는지 확인 |

**통과 조건**:

- z1, z2, z3에서 h0 복원 성능이 stage에 따라 일관된 곡선을 보인다.
- z3가 너무 쉽게 h0를 복원하지 않는다. 즉, 병목이 실제로 존재한다.
- z3가 너무 무의미하지도 않다. semantic metric이 완전히 붕괴하면 실패다.

---

## Phase 2. Forward Process Isolation - Small

**목표**: forward process만 바꿔서 compression의 이득을 검증한다.

기존 대규모 V1~V5 비교를 다음 3종으로 줄인다.

| 모델 | Forward process | 학습 대상 |
|---|---|---|
| B1. Latent Gaussian | h0에 Gaussian noise 추가 | 동일 reverse module |
| B2. Latent Mask/Pooling | latent token mask 또는 average pooling | 동일 reverse module |
| B3. LACE-small | attention compression path | compressor + 동일 reverse module |

**통제 조건**:

- 같은 frozen encoder
- 같은 데이터 subset
- 같은 sequence length
- 같은 reverse module capacity
- 같은 학습 step 수
- 가능하면 같은 random seed 1개, 여유가 있으면 seed 3개

**핵심 비교**:

```text
B3 > B1/B2 on semantic preservation
```

**필수 metric**:

| 카테고리 | 1차 metric | 비고 |
|---|---|---|
| latent 복원 | MSE, cosine | 가장 싸고 안정적 |
| 의미 보존 | sentence embedding cosine | BERTScore보다 가볍게 시작 |
| 표면 보존 | token overlap, edit distance | 표면 정보 손실 확인 |
| collapse 검사 | latent variance, perturbation sensitivity | shortcut 방지 |

**선택 metric**:

| metric | 도입 시점 |
|---|---|
| BERTScore | Phase 2 결과가 괜찮을 때 |
| NLI entailment | text renderer가 안정화된 뒤 |
| QA consistency | scale-up 전 |
| MINE | 최종 논문용. 1차 실험에서는 제외 |

---

## Phase 3. Minimal Text Generation Demo

**목표**: latent 실험이 텍스트 생성으로 이어질 수 있음을 작은 demo로 보인다.

| 항목 | 설정 |
|---|---|
| 데이터 | XSum 5k~20k 또는 CNN/DailyMail 10k subset |
| 입력 | source document 또는 compressed summary |
| 출력 | target summary/reconstruction |
| 모델 | frozen encoder + LACE-small + lightweight renderer |

처음부터 long-form generation을 하지 않는다. 추천 task는 다음 둘 중 하나다.

| Task | 장점 |
|---|---|
| 의미 보존 재작성 | output length가 짧고 평가가 쉬움 |
| XSum-style short summary reconstruction | 고압축 의미 보존과 잘 맞음 |

**통과 조건**:

- generated text가 완벽하지 않아도 reference와 semantic similarity가 baseline보다 높다.
- surface overlap만 높고 semantic metric이 낮으면 실패다.
- decoder가 latent를 무시하는 경우, latent ablation 시 output이 거의 변하지 않는다. 이 경우 renderer capacity를 낮추거나 adapter 구조로 바꾼다.

---

## Phase 4. Scale-Up Decision

Phase 0~3에서 유효 신호가 있을 때만 스케일업한다.

| 조건 | 다음 행동 |
|---|---|
| B3가 B1/B2보다 latent semantic metric에서 우위 | 데이터 50k~100k로 확대 |
| text demo에서도 semantic metric 우위 | 논문용 small-scale 결과 정리 |
| compression은 좋지만 text가 약함 | renderer 연구로 분리 |
| compression도 baseline보다 약함 | 가설 수정 또는 연구 중단 |

스케일업은 다음 순서로 한다.

```text
T5-small frozen
→ T5-base frozen
→ encoder/decoder LoRA
→ selected modules fine-tuning
→ scale-matched DLM baseline
```

## 6. Baseline 축소안

### 6.1 반드시 필요한 baseline

| Baseline | 이유 |
|---|---|
| Latent Gaussian | 기존 latent diffusion 계열과 직접 비교 |
| Latent Mask/Pooling | compression이 단순 dimensionality reduction 이상인지 확인 |
| No-compression autoencoder | compression path 자체가 성능을 망치지 않는지 확인 |

### 6.2 후순위 baseline

| Baseline | 도입 시점 |
|---|---|
| Masked token DLM | Phase 2가 성공한 뒤 |
| T5/BART denoising fine-tune | text demo가 안정화된 뒤 |
| LLaDA-small 재구현 | 외부 compute 확보 후 |
| AR Transformer from scratch | 최종 논문 scale-up에서만 |

처음부터 LLaDA-small을 재학습하지 않는다. 1차 연구의 적은 **LLaDA**가 아니라 **Gaussian/mask forward process**다.

## 7. 정보율 측정의 현실 버전

기존 문서의 MINE 기반 MI 추정은 논문 최종 단계로 미룬다. 1차 실험에서는 proxy를 사용한다.

### 7.1 필수 proxy

| Proxy | 측정 방법 | 기대 패턴 |
|---|---|---|
| Latent token budget | N_t / N_0 | t가 커질수록 감소 |
| Reconstruction MSE | z_t → h0 복원 오차 | t가 커질수록 증가 |
| Cosine similarity | z_t → h0 복원 방향성 | t가 커질수록 감소 |
| Surface recovery | token overlap/edit distance | 빠르게 감소 |
| Semantic similarity | sentence embedding cosine | 천천히 감소 |

### 7.2 주장 가능 범위

1차 실험에서는 다음처럼 주장한다.

> We operationalize information rate by latent token budget and reconstruction capacity, and verify that stronger compression removes surface detail faster than semantic content.

아직 다음 주장은 하지 않는다.

> We precisely estimate mutual information I(z_t; h0) in nats/token.

정확한 mutual information 추정은 scale-up 논문 단계에서 추가한다.

## 8. 성공/실패 Gate

### 8.1 최소 성공 기준

| Gate | 기준 |
|---|---|
| G1. 압축 곡선 | z1 → z2 → z3로 갈수록 reconstruction MSE가 단조 증가 |
| G2. 의미 보존 | semantic similarity가 surface overlap보다 천천히 감소 |
| G3. baseline 비교 | LACE-small이 Gaussian 또는 mask baseline보다 semantic metric에서 우위 |
| G4. latent 사용 | latent perturbation/dropout 시 output 또는 reconstruction이 유의미하게 변함 |

### 8.2 중단 기준

| 실패 양상 | 해석 | 대응 |
|---|---|---|
| z3가 h0를 거의 완벽히 복원 | bottleneck이 너무 약함 | latent token 수 감소 |
| z1부터 의미가 붕괴 | bottleneck이 너무 강함 | compression 단계 완화 |
| B3가 B1/B2보다 항상 낮음 | compression inductive bias 약함 | attention pooling 구조 재검토 |
| renderer가 latent를 무시 | decoder prior가 너무 강함 | frozen decoder 대신 adapter/shallow decoder |
| metric이 불안정 | 데이터/평가가 작음 | 5k → 20k로 확대 |

## 9. 1차 결과물

개인 연구자의 첫 번째 목표는 큰 모델 checkpoint가 아니다. 다음 산출물을 목표로 한다.

1. `LACE-small` 구현
2. latent compression/expansion 학습 script
3. Gaussian, mask/pooling, LACE 비교 table
4. compression level별 metric plot
5. latent perturbation sensitivity 결과
6. 20~50개 text generation sample
7. "scale-up할 가치가 있는가"에 대한 짧은 연구 노트

이 정도가 나오면 다음 단계로 논문용 실험 설계를 다시 키운다.

## 10. 추천 실행 순서

### Sprint 1. 데이터와 latent cache

- WikiText-2 또는 XSum subset loader 작성
- T5-small encoder로 h0를 추출
- h0를 disk cache로 저장
- sequence length, padding, attention mask 처리 검증

**검증**:

- 100개 sample에서 h0 shape가 일정하다.
- cache 재로딩 후 값이 보존된다.

### Sprint 2. Pooling baseline

- average pooling으로 z1/z2/z3 생성
- simple expander로 h0 복원
- MSE/cosine curve 출력

**검증**:

- 학습 loss가 감소한다.
- z3 복원이 z1보다 어렵다.

### Sprint 3. Attention LACE-small

- learned query attention pooling 구현
- stage별 expander 구현
- B2 pooling baseline과 같은 조건에서 학습

**검증**:

- LACE-small이 pooling baseline보다 semantic proxy에서 나은지 확인한다.

### Sprint 4. Gaussian baseline

- h0에 stage별 Gaussian noise를 주입
- 같은 expander capacity로 복원
- LACE-small과 비교

**검증**:

- 동일 reconstruction difficulty 근처에서 semantic preservation을 비교한다.

### Sprint 5. Text renderer demo

- frozen T5 decoder 또는 lightweight decoder 연결
- 20~50개 qualitative sample 생성
- latent ablation test 수행

**검증**:

- latent를 바꾸면 output이 바뀐다.
- baseline보다 semantic metric이 나은 sample cluster가 존재한다.

## 11. 논문 스케일업 로드맵

1차 결과가 긍정적이면 원래 Claude protocol의 일부를 되살린다.

| Scale-up 항목 | 되살리는 시점 |
|---|---|
| BERTScore/NLI/QA consistency | text demo가 안정화된 뒤 |
| seed 3개 반복 | 1개 seed에서 방향성이 확인된 뒤 |
| MINE 기반 MI 추정 | 논문 제출 전 핵심 claim 강화 시 |
| XSum/CNN full fine-tune | subset 결과가 긍정적일 때 |
| LLaDA-small 또는 masked DLM 재구현 | compute 확보 후 |
| long-context generation | short generation에서 성공한 뒤 |

---

## 12. 현재 연구의 주장 한계

스케일다운 실험에서 주장할 수 있는 것:

- learned compression path가 Gaussian/mask corruption보다 semantic latent를 더 잘 보존할 가능성
- diffusion time을 information-rate proxy로 정의하는 실험적 framework
- 작은 scale에서 forward process isolation 결과

스케일다운 실험만으로 주장하면 안 되는 것:

- LLaDA 같은 large DLM보다 성능이 좋다
- exact mutual information을 측정했다
- long-context generation에서 topic drift가 줄었다
- SOTA summarization/generation 성능을 달성했다

이 선을 지키면, 작은 연구라도 과장 없이 탄탄하게 쌓을 수 있다.
