의미 골격과 위치 보조 구조는
무작위 손상보다 더 나은 역방향 궤적을 만든다.

LACE는 diffusion language modeling의 forward process를 무작위 corruption 대신 중요도 기반 압축으로 재정의합니다. Forward terminal state는 의미를 담은 골격이고, 역방향 학습은 골격을 다시 문장으로 확장합니다. S0–S2a 단계는 통과됐고, S3 anchor 베이스라인 비교는 핵심 gate를 통과하지 못했습니다. S3a 진단은 content terminal 신호를 일부 회복했지만, 위치 scaffold와 predicted-anchor confound가 남아 있습니다.

Semantic skeleton + positional scaffold creates a better reverse trajectory than random corruption.

03 · 핵심 개념

Forward를 무작위 손상이 아닌 압축으로 본다

Forward process를 의미 보존을 추구하는 압축 trajectory로 다시 정의합니다. 시간 t는 부패 정도가 아니라 보존된 의미 정보율이 됩니다.

Semantic skeleton

의미 골격

Forward process의 최종 압축 상태. entity·event·relation처럼 핵심 의미를 담은 high-importance token만 남깁니다. 무작위 손상의 terminal noise가 아니라 content-bearing terminal state로 다룹니다.

Positional scaffold

위치 보조 구조

의미 골격을 다시 문장으로 확장할 때 어순과 문법 흐름을 유지하도록 돕는 보조 구조. 위치 신호만으로 좋아진 결과는 의미 골격 사용의 증거로 취급하지 않습니다 — position-only control로 분리합니다.

Reverse trajectory

역방향 궤적

골격에서 점진적으로 풍부한 중간 상태를 거쳐 원문으로 확장하는 학습 과정. denoising이 아니라 expansion입니다. 학습은 x_t → x_{t-1} 또는 x_t → x_0로 정의됩니다.

06 · 남은 질문

아직 방어할 수 없는 것

현재 가진 결과로는 아직 결론낼 수 없는 항목들. 다음 실험은 이들 중 하나 이상을 직접 분리하도록 설계됩니다.

caveat위치 편향

position_prior가 여전히 강함

S1 Hit@1 0.8154, S2 keyword recall 0.8504. WikiText의 sentence-initial bias가 강해서 의미 골격의 효과를 위치 신호와 분리해 측정하는 control이 계속 필요합니다.

openscorer 선택

attention vs idf — 누가 우위인가

idf_scaffold는 loss 2.4851로 가장 낮지만 attention_scaffold의 token F1이 더 높습니다. 결과는 "중요도 기반 골격 계열 > 무작위"로 해석하고, 단일 scorer 우위 주장은 보류합니다.

caveat생성 미검증

open-ended generation은 아직 미증명

S0–S3a는 reconstruction proxy (token F1, ROUGE-L, teacher-forced loss). S3a도 S4 준비 신호가 아니라 진단 결과이므로 open-ended generation의 의미 일관성·반복 제어는 아직 평가 대상으로 올리지 않습니다.

nextS3b 보정

probe가 무엇을 쓰는가

S3a에서 attention_terminal은 random control보다 높았지만 position_only가 가까웠고 predicted anchor가 최고였습니다. 다음에는 같은 학습 모델에서 입력만 바꾸는 ablation과 반복률·entity metric을 추가해야 합니다.
