## 2. 연구 배경

최근 Diffusion Language Model, 이하 DLM은 autoregressive language model의 대안으로 주목받고 있다. 대표적으로 LLaDA는 대규모 언어 확산 모델을 masked token prediction 방식으로 학습하며, 순방향 과정에서는 데이터를 마스킹하고 역방향 과정에서는 마스크된 토큰을 복원하는 구조를 사용한다. ([arXiv][1])

기존 DLM의 강점은 다음과 같다.

| 항목     | 설명                         |
| ------ | -------------------------- |
| 병렬 생성  | 여러 토큰을 동시에 갱신할 수 있음        |
| 양방향 문맥 | 왼쪽과 오른쪽 문맥을 모두 활용 가능       |
| 반복 수정  | 한 번 생성한 토큰을 다시 고칠 수 있음     |
| 제어 가능성 | 특정 위치, 길이, 조건을 고정한 채 생성 가능 |

DLM survey에서도 DLM의 주요 장점으로 병렬적 denoising, 양방향 문맥, 세밀한 제어가 언급된다. ([arXiv][2])

그러나 텍스트에 diffusion을 적용할 때 핵심적인 문제가 있다. 이미지에서는 Gaussian noise를 추가하는 과정이 자연스럽지만, 언어는 discrete token으로 구성되어 있어 “노이즈 추가”가 실제로는 token masking, token replacement, random corruption에 가깝다. 이 과정은 언어의 의미 구조를 반영하기보다는, 표면 토큰을 임의로 손상시키는 방식이다.

따라서 본 연구는 다음 문제의식에서 출발한다.

> 언어 생성에서 diffusion time은 “노이즈의 강도”가 아니라, “정보 압축의 정도”로 정의되어야 하지 않을까?

## 2.5 선행연구 비교 및 차별화 (요약)

> 상세 분석은 [선행연구비교.md](./선행연구비교.md) 참조.

본 연구의 핵심 위험은 "기존 latent diffusion의 단순 재해석"으로 보이는 것이다. 가장 가까운 8개 선행연구를 다섯 축(순방향 신호, 표현 공간, 시간축 의미, bottleneck 메커니즘, 정보율 제어)으로 비교하여 차별점을 명시한다.

| 모델 | 순방향 신호 | 시간축 의미 | 정보율 제어 |
|---|---|---|---|
| Diffusion-LM, SSD-LM, Plaid, GENIE, LD4LG | Gaussian noise | noise variance / log-SNR | 암묵적 |
| LLaDA | mask corruption | mask ratio | 이산 mask ratio |
| Optimus / DELLA | 없음 (정적 VAE) | 계층 깊이 (시간 아님) | β-VAE |
| Funnel / Perceiver | 없음 (encoder만) | encoder 깊이 | 차원 축소율 |
| **LACE (제안)** | **information compression** | **information rate I(z_t; h₀)** | **명시적 (MINE / rate budget)** |

**핵심 차별점 두 가지:**

* **(D1)** 순방향 과정이 stochastic corruption이 아니라 **deterministic information bottleneck**이다. 선행연구 대부분은 t가 커질수록 entropy가 늘지만, LACE는 t가 커질수록 mutual information I(z_t; h₀)이 줄어든다.
* **(D2)** 시간축 t의 정의가 noise variance나 mask ratio가 아니라 **information rate (nats/token)**이다. LACE는 diffusion(시간축 있음)과 hierarchical VAE(압축 있음)의 교집합 영역에서 비어 있던 한 칸을 채운다.

## 3. 문제 정의

기존 DLM의 순방향 과정은 대체로 다음과 같다.

```text
x₀ = 원문 토큰열
x₁ = 일부 토큰이 마스킹된 문장
x₂ = 더 많은 토큰이 마스킹된 문장
...
x_T = 거의 모든 토큰이 마스킹된 문장
```

모델은 역방향 과정에서 다음을 학습한다.

```text
pθ(x_{t-1} | x_t)
```

즉, 손상된 토큰열에서 덜 손상된 토큰열을 복원한다.

하지만 언어 생성은 본질적으로 다음 과정에 더 가깝다.

```text
의도 / 의미 / 구조
→ 문장 계획
→ 구체적 표현
→ 표면 토큰
```

따라서 본 연구는 DLM의 순방향 과정을 다음과 같이 재정의한다.

```text
원문 token representation
→ 약하게 압축된 latent representation
→ 더 압축된 semantic latent
→ 고도로 압축된 information bottleneck
```

그리고 역방향 과정은 다음을 학습한다.

```text
고압축 semantic latent
→ 저압축 detailed latent
→ token-level representation
→ text
```

## 4. 핵심 연구 아이디어

본 연구는 기존 DLM의 **corruption-based 순방향 과정**을 **compression-based 순방향 과정**으로 대체한다.

### 기존 방식

```text
토큰열
→ random mask / noise
→ denoising
→ text
```

### 제안 방식

```text
토큰열
→ vector representation
→ progressive information compression
→ expansion process
→ text
```

즉, 본 연구의 핵심은 다음 문장으로 요약된다.

> **Diffusion time은 corruption severity가 아니라 information rate에 대응해야 한다.**

## 5. 연구 목표

본 연구의 목표는 다음 세 가지다.

### 목표 1. 정보 압축 기반 latent diffusion framework 제안

텍스트를 직접 마스킹하는 대신, encoder가 만든 continuous latent representation을 단계적으로 압축하고, 이 압축 단계들을 diffusion trajectory로 사용한다.

### 목표 2. 언어적 의미 보존에 적합한 compression schedule 설계

단순히 차원을 줄이는 것이 아니라, 표면 표현 정보는 점진적으로 줄이고 의미 정보는 최대한 유지하는 compression bottleneck을 설계한다.

### 목표 3. 기존 DLM 대비 생성 품질과 의미 일관성 검증

masked diffusion, latent Gaussian diffusion, autoregressive generation과 비교하여 제안 모델이 긴 텍스트 생성, 의미 보존 재작성, 요약 기반 확장, controlled generation에서 더 나은 성능을 보이는지 평가한다.

## 6. 제안 모델: LACE

모델 이름은 **LACE: Latent Adaptive Compression and Expansion for Language Diffusion**으로 정한다.

## 6.1 전체 구조

```text
입력 text x
↓
Encoder
↓
h₀: token-level latent representation
↓
Compression path
↓
z₁: mildly compressed latent
↓
z₂: moderately compressed latent
↓
z₃: highly compressed semantic latent
↓
z_T: information bottleneck
```

역방향 generation은 다음과 같다.

```text
z_T
→ z_{T-1}
→ ...
→ z₂
→ z₁
→ h₀
→ Decoder / Renderer
→ generated text
```

---

## 6.2 Encoder

입력 문장 또는 문서를 encoder가 latent representation으로 변환한다.

```text
h₀ = Enc(x), h₀ ∈ R^{N × d}
```

여기서 `N`은 latent token 수, `d`는 hidden dimension이다.

초기 구현에서는 다음 중 하나를 사용할 수 있다.

| Encoder 후보                      | 장점                          |
| ------------------------------- | --------------------------- |
| T5/BART encoder                 | encoder-decoder 구조와 잘 맞음    |
| 사전학습 LM hidden states        | 기존 LLM representation 활용 가능 |
| lightweight Transformer encoder | 실험 통제 용이                    |

Latent Diffusion for Language Generation 연구는 사전학습 encoder-decoder의 latent space에서 continuous diffusion을 수행하고, decoder를 통해 자연어로 복원하는 접근을 제안했다. ([arXiv][3]) 본 연구는 이 흐름을 따르되, 단순 Gaussian noise가 아니라 **progressive compression**을 diffusion trajectory로 사용한다는 점에서 차별화된다.

---

## 6.3 Compression Path

핵심 모듈은 latent representation을 여러 단계로 압축하는 compression path다.

예시:

```text
h₀ ∈ R^{128 × 768}
z₁ ∈ R^{64 × 768}
z₂ ∈ R^{32 × 768}
z₃ ∈ R^{16 × 768}
z₄ ∈ R^{8 × 768}
```

압축 방식은 다음 후보를 비교한다.

| 방식                     | 설명                               | 장점               | 위험                    |
| ---------------------- | -------------------------------- | ---------------- | --------------------- |
| Latent token pooling   | latent token 수를 줄임               | 간단하고 안정적         | 의미 압축 보장 약함           |
| Attention bottleneck   | learnable query로 정보 추출           | 유연함              | query가 shortcut 학습 가능 |
| Variational bottleneck | latent에 stochastic bottleneck 부여 | diffusion과 궁합 좋음 | posterior collapse 가능 |
| VQ bottleneck          | codebook으로 latent 양자화            | 해석 가능성           | codebook collapse 가능  |
| Low-rank compression   | representation rank 제한           | 정보율 제어 명확        | 구현 난도 높음              |

초기 연구에서는 **attention bottleneck + latent token pooling**을 기본 구조로 사용한다.

---

## 6.4 Reverse Expansion Process

기존 diffusion은 noise latent에서 clean latent를 복원한다.

```text
z_noise → z_clean
```

본 연구는 압축 latent에서 상세 latent를 복원한다.

```text
z_highly_compressed → z_less_compressed → h₀
```

학습 목표는 다음과 같다.

```text
L_stage = Σ_t || Expand_t(z_t) - z_{t-1} ||²
```

또는 확률적으로:

```text
L_stage = -Σ_t log pθ(z_{t-1} | z_t, t)
```

여기서 `t`는 noise level이 아니라 **compression level**이다.

---

## 6.5 Renderer

최종 latent `ĥ₀`를 텍스트로 변환한다.

```text
x̂ = Renderer(ĥ₀)
```

Renderer는 다음 중 하나로 구현한다.

| Renderer                    | 설명                                  |
| --------------------------- | ----------------------------------- |
| 사전학습 decoder            | T5/BART decoder 등                   |
| shallow Transformer decoder | latent 사용을 강제하기 쉬움                  |
| diffusion token decoder     | 마지막 단계에서 masked token refinement 수행 |

초기에는 사전학습 encoder-decoder 기반 renderer를 사용하고, 이후 token-level refinement를 추가한다.

---

## 7. 학습 목적 함수

전체 loss는 다음과 같이 구성한다.

```text
L = L_recon + λ L_stage + β L_info + γ L_sem
```

각 항목의 의미는 다음과 같다.

| Loss       | 목적                 |
| ---------- | ------------------ |
| `L_recon`  | 최종 텍스트 복원          |
| `L_stage` | 압축 단계 간 expansion 복원 |
| `L_info`   | latent 정보량 제어      |
| `L_sem`    | 의미 보존 제약           |

---

## 7.1 Reconstruction Loss

최종 출력 텍스트가 원문 또는 목표 텍스트를 잘 복원하도록 한다.

```text
L_recon = -log pθ(x | ĥ₀)
```

---

## 7.2 Stage Reconstruction Loss

각 압축 단계에서 이전 단계 latent를 복원하도록 학습한다.

```text
L_stage = Σ_t d(ẑ_{t-1}, z_{t-1})
```

거리 함수 `d`는 MSE, cosine distance, contrastive loss 등을 사용할 수 있다.

---

## 7.3 Information Bottleneck Loss

압축 단계가 실제로 정보를 줄이도록 rate constraint를 둔다.

예:

```text
t가 증가할수록 I(z_t; h₀)이 감소해야 함
```

실용적으로는 다음 방식으로 구현한다.

* latent token 수 감소
* latent dropout
* KL regularization
* VQ codebook size 제한
* latent에 noise injection
* rank constraint

---

## 7.4 Semantic Preservation Loss

압축 latent가 표면 표현은 잃더라도 의미는 유지하도록 한다.

가능한 구현:

| 방식                           | 설명                                  |
| ---------------------------- | ----------------------------------- |
| embedding similarity         | 원문과 복원문의 sentence embedding 유사도     |
| NLI entailment               | 원문과 생성문이 의미적으로 모순되지 않는지 평가          |
| QA consistency               | 원문에서 답할 수 있는 질문을 생성문에서도 답할 수 있는지 평가 |
| entity-relation preservation | 핵심 entity와 relation 보존 여부           |

---

## 8. 연구 가설

## H1. Compression-based diffusion은 random masking 기반 DLM보다 의미 일관성을 더 잘 보존한다.

기존 masking은 토큰을 임의로 숨기므로 문장의 관계 구조를 깨뜨릴 수 있다. 반면 latent compression은 representation bandwidth를 줄이면서도 의미 정보를 유지하도록 설계할 수 있다.

---

## H2. Diffusion time을 information rate로 정의하면 긴 텍스트 생성에서 topic drift가 줄어든다.

긴 텍스트 생성에서는 token-level local fluency보다 discourse-level structure가 중요하다. 압축 latent는 이러한 고수준 구조를 보존하는 데 유리할 수 있다.

---

## H3. Semantic latent에서 token latent로 점진 복원하는 방식은 one-shot latent decoding보다 controllability가 높다.

단일 latent에서 바로 텍스트를 생성하는 방식보다, 여러 압축 수준을 거치는 방식이 중간 단계 제어와 수정에 더 적합하다.

---

## H4. Token-level refinement를 결합하면 fluency와 semantic fidelity를 동시에 개선할 수 있다.

semantic latent diffusion만 사용하면 문장이 어색할 수 있고, token diffusion만 사용하면 의미 구조가 약할 수 있다. 두 방식을 결합하면 상호 보완이 가능하다.

---

## 9. 실험 설계 (요약)

> 상세 프로토콜, 연산 자원 가정, phase별 게이트, information rate 측정 방법은 [실험설계.md](./실험설계.md) 참조.

본 연구의 실험은 세 단계 decision-gated 구조다.

* **Phase A (2~4개월차): 소규모 개념 검증** — 125M 규모, 순방향 과정 분리 비교
* **Phase B (4~6개월차): 확장 비교** — 350M 규모, 조건 일치 baseline 비교
* **Phase C (6~7개월차): 긴 문맥 및 제어 가능성** — 긴 문서 생성, controlled generation

**핵심 scope 한정:** SOTA 절대 성능을 노리지 않는다. **동일 연산 자원 / 동일 데이터 / 동일 backbone에서 순방향 과정 설계의 효과를 분리**한다. LLaDA(8B)와는 동일 scale로 재학습한 LLaDA-small(125M, 350M)을 비교 baseline으로 사용한다.

가장 중요한 단일 실험은 **순방향 과정 분리 비교**다. 동일 backbone에서 V1(masked) / V2(latent Gaussian) / V3(latent mask) / V4(latent pooling only) / V5(LACE)만 바꿔 학습 후 비교한다.

Information rate는 단일 측정에 의존하지 않고 ① MINE 기반 mutual information 추정, ② linear probing accuracy (token vs semantic), ③ reconstruction MSE 세 방법으로 교차 확인한다.

## 10. Ablation Study (절제 실험)

## 10.1 압축 단계 수

```text
2단계 / 3단계 / 4단계 / 5단계 compression
```

목적:

* 압축 단계가 너무 적으면 diffusion 효과가 약함
* 너무 많으면 error accumulation이 생길 수 있음

## 10.2 압축 방식 비교

```text
token pooling
attention bottleneck

low-rank bottleneck
```

목적:

* 어떤 compression mechanism이 의미 보존에 가장 적합한지 확인

## 10.3 정보율 제어 강도

```text
weak bottleneck / medium bottleneck / strong bottleneck
```

목적:

* 압축이 약하면 표면 정보를 그대로 숨길 위험
* 압축이 강하면 의미 정보도 손실될 위험


## 10.5 Renderer capacity (용량)

```text
weak decoder / medium decoder / strong decoder
```

목적:

* decoder가 너무 강하면 latent를 무시하고 language prior만으로 생성할 수 있음
* latent 사용 여부를 확인하기 위한 중요한 ablation

## 12. 예상 한계와 대응 방안

## 한계 1. Latent compression이 실제로 의미 압축인지 보장하기 어렵다.

대응:

* semantic preservation loss 추가
* latent probing 실험 수행
* entity/relation preservation 평가
* 압축 단계별 nearest neighbor 분석

---

## 한계 2. Decoder가 latent를 무시할 수 있다.

대응:

* decoder capacity 제한
* latent dropout ablation
* latent perturbation sensitivity test
* mutual information regularization

---

## 한계 3. 압축이 강하면 다양한 복원이 가능해져 exact reconstruction이 어려워진다.

대응:

* exact match보다 semantic fidelity 중심 평가 사용
* multiple valid generation 평가 도입
* human preference evaluation 수행

---

## 한계 4. 기존 latent diffusion과 차별성이 약해 보일 수 있다.

대응:

본 연구의 차별점은 단순히 latent space에서 diffusion을 수행하는 것이 아니라, **diffusion time을 noise level이 아니라 compression rate로 정의**한다는 점이다. 기존 latent diffusion for language는 continuous latent representation에서 diffusion을 수행하는 데 초점을 두지만, 본 연구는 progressive information bottleneck을 순방향 과정으로 사용한다. ([arXiv][3])

## 13. 연구 기여점

본 연구의 기여는 다음 세 가지로 정리할 수 있다.

### 기여 1. DLM 순방향 과정의 재정의

기존 DLM의 random token corruption을 대체하여, latent information compression을 순방향 과정으로 제안한다.

### 기여 2. Information-rate diffusion framework 제안

diffusion time을 noise level이 아니라 information rate로 해석하는 새로운 언어 생성 프레임워크를 제안한다.

### 기여 3. 의미 충실도 중심의 DLM 평가 체계 제안

DLM을 token reconstruction 성능이 아니라, 의미 보존, 긴 문맥 일관성, controlled generation 관점에서 평가한다.

## 15. 최종 연구 요약

본 연구는 기존 DLM의 핵심 가정에 문제를 제기한다. 현재 많은 DLM은 언어를 이미지 diffusion처럼 다루기 위해 token masking 또는 random corruption을 순방향 과정으로 사용한다. 그러나 언어는 discrete token의 표면 배열이 아니라 의미, 관계, 담화 구조, 의도를 포함하는 계층적 정보 구조다.

따라서 본 연구는 텍스트에 노이즈를 추가하는 대신, 텍스트의 latent representation을 점진적으로 압축하고, 모델이 이를 다시 복원하도록 학습하는 **LACE: Latent Adaptive Compression and Expansion for Language Diffusion**을 제안한다.

핵심 주장은 다음과 같다.

> 언어 확산 모델에서 diffusion time은 corruption severity가 아니라 information rate로 정의되어야 한다.

이를 통해 본 연구는 DLM을 단순한 masked token reconstruction 모델에서 벗어나, 의미 정보의 압축과 복원을 수행하는 새로운 생성 모델 패러다임으로 확장하고자 한다.
