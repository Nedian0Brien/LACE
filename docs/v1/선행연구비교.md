# 선행연구 비교 및 차별화

> 본 문서는 [연구기획서.md](./연구기획서.md) §2.5의 상세 버전이다. LACE (Latent Adaptive Compression and Expansion for Language Diffusion)를 가장 가까운 8개 선행연구와 다섯 축으로 비교하고, 인접 위험에 대한 반론까지 정리한다.

---

## 1. 비교 대상 선정 기준

본 연구의 핵심 위험은 "기존 latent diffusion의 단순 재해석"으로 보일 수 있다는 점이다. 따라서 비교 대상은 다음 세 카테고리에서 선정한다.

1. **Diffusion Language Model 계열** — 순방향 과정을 token/latent corruption으로 정의한 선행연구
2. **Hierarchical / Latent VAE 계열** — 시간축은 없지만 단계적 정보 압축을 수행하는 모델
3. **Compression encoder 계열** — 생성형 역방향 과정은 없지만 입력을 단계적으로 압축하는 모델

LACE는 (1)의 시간축, (2)의 계층적 compression, (3)의 명시적 정보율 제어를 모두 가지는 교집합 영역에 위치한다.

---

## 2. 모델별 상세 비교

### 2.1 Diffusion-LM (Li et al., 2022)
- **순방향 신호**: continuous embedding에 Gaussian noise 추가
- **시간축**: noise variance σ²(t)
- **Bottleneck**: 없음 (전체 embedding dimension 유지)
- **정보율 제어**: 암묵적 (noise schedule에 의존)
- **LACE와의 차이**: representation 차원이 시간에 따라 변하지 않는다. 정보 손실은 noise injection의 부수효과일 뿐 명시적 bandwidth 제약이 아니다.
- **참조**: [arXiv:2205.14217](https://arxiv.org/abs/2205.14217)

### 2.2 SSD-LM (Han et al., 2022)
- **순방향 신호**: semi-autoregressive block 단위 Gaussian noise
- **시간축**: noise level + block position
- **Bottleneck**: 없음
- **정보율 제어**: 암묵적
- **LACE와의 차이**: SSD-LM은 generation 단위를 block으로 나누어 부분적 autoregressive 구조를 갖지만, 각 block 내부의 순방향 과정은 여전히 noise-based다.
- **참조**: [arXiv:2210.17432](https://arxiv.org/abs/2210.17432)

### 2.3 Plaid (Gulrajani & Hashimoto, 2023)
- **순방향 신호**: log-SNR로 parameterize된 Gaussian noise
- **시간축**: log-SNR (정보이론적 해석 가능)
- **Bottleneck**: 없음
- **정보율 제어**: 부분적 — log-SNR이 channel capacity와 연결되어 있어 가장 인접한 위험
- **LACE와의 차이**: Plaid의 log-SNR는 *추가된 noise의 정보이론적 양*을 측정하지만, latent의 *capacity 자체*를 단계적으로 줄이지는 않는다. 즉 representation은 항상 같은 차원을 가지며 정보 손실은 SNR 감소로만 발생한다.
- **참조**: [arXiv:2305.18619](https://arxiv.org/abs/2305.18619)

### 2.4 GENIE (Lin et al., 2022)
- **순방향 신호**: continuous diffusion + autoregressive cross-attention
- **시간축**: noise variance
- **Bottleneck**: 없음
- **정보율 제어**: 암묵적
- **LACE와의 차이**: GENIE는 사전학습된 LM을 backbone으로 활용하지만 순방향 과정은 standard Gaussian이다.
- **참조**: [arXiv:2212.11685](https://arxiv.org/abs/2212.11685)

### 2.5 LD4LG — Latent Diffusion for Language Generation (Lovelace et al., 2022)
- **순방향 신호**: 사전학습 encoder의 latent space에 Gaussian noise
- **시간축**: noise variance
- **Bottleneck**: encoder 자체가 정적 압축을 수행하지만, diffusion 단계 간 추가 압축은 없음
- **정보율 제어**: 암묵적
- **LACE와의 차이**: **가장 인접한 위험**. LD4LG도 latent에서 diffusion을 수행하지만, 시간축에서 latent의 *bandwidth*가 변하지 않는다. LACE는 z_t의 *차원 수 자체*가 시간에 따라 변한다 (z_t ∈ R^{N_t × d}, N_t는 t의 함수).
- **참조**: [arXiv:2212.09462](https://arxiv.org/abs/2212.09462)

### 2.6 LLaDA (Nie et al., 2025)
- **순방향 신호**: discrete token masking
- **시간축**: mask ratio ∈ [0, 1]
- **Bottleneck**: 없음 (mask는 정보 *제거*이지 압축이 아님)
- **정보율 제어**: 이산적 (mask ratio = 정보 손실율)
- **LACE와의 차이**: 가장 강력한 large-scale DLM baseline. LLaDA의 시간축은 정보 손실율과 직접 대응하지만, 손실 메커니즘이 *random corruption*이다. LACE는 deterministic compression을 통해 *어떤 정보를 잃을지*를 학습한다.
- **참조**: [arXiv:2502.09992](https://arxiv.org/abs/2502.09992)

### 2.7 Optimus / DELLA (Li et al., 2020 / Hu et al., 2022)
- **순방향 신호**: 없음 (정적 hierarchical VAE)
- **시간축**: 계층 깊이 (시간 차원 아님)
- **Bottleneck**: 명시적 (각 계층에 latent code, β-VAE로 capacity 제어)
- **정보율 제어**: β-VAE의 KL term
- **LACE와의 차이**: hierarchical compression은 공유하지만 *generative reverse trajectory*가 없다. Optimus는 single shot으로 z를 sampling하고 decode하므로 iterative refinement, controllability, 중간 단계 조작이 불가능하다.

### 2.8 Funnel Transformer / Perceiver-AR (Dai et al., 2020 / Hawthorne et al., 2022)
- **순방향 신호**: encoder 내부에서 sequence 길이를 단계적으로 축소
- **시간축**: encoder depth (시간 차원 아님)
- **Bottleneck**: 명시적 (length reduction)
- **정보율 제어**: 차원 축소율
- **LACE와의 차이**: compression 자체는 유사하지만 *generative model이 아니다*. Funnel은 representation learning을 위한 encoder이고 reverse expansion을 학습하지 않는다.

## 3. 5축 비교 매트릭스

| 모델 | 순방향 신호 | 표현 공간 | 시간축 의미 | Bottleneck 메커니즘 | 정보율 제어 |
|---|---|---|---|---|---|
| Diffusion-LM | Gaussian noise | continuous embedding (R^{N×d}) | noise variance σ²(t) | 없음 | 암묵적 |
| SSD-LM | Gaussian noise (block) | continuous embedding | noise + block | 없음 | 암묵적 |
| Plaid | Gaussian noise | continuous embedding | log-SNR | 없음 | 부분적 (log-SNR) |
| GENIE | Gaussian noise | continuous embedding | noise variance | 없음 | 암묵적 |
| LD4LG | Gaussian noise | pretrained latent (고정 차원) | noise variance | 정적 (encoder만) | 암묵적 |
| LLaDA | mask corruption | discrete token | mask ratio | 없음 | 이산 mask ratio |
| Optimus / DELLA | 없음 | hierarchical latent | 계층 깊이 (시간 ✗) | β-VAE KL | β-VAE β |
| Funnel / Perceiver | 없음 | length-reduced | encoder depth (시간 ✗) | length reduction | 차원 축소율 |
| **LACE (제안)** | **information compression** | **가변 차원 latent (R^{N_t × d})** | **information rate I(z_t; h₀)** | **attention bottleneck + rate constraint** | **명시적 (MINE / rate budget)** |

## 4. 핵심 차별점

### D1. 순방향 과정은 stochastic corruption이 아니라 deterministic information bottleneck이다.

| 비교 항목 | 선행연구 (1.1~1.6) | LACE |
|---|---|---|
| 정보 변화 방향 | t↑ ⇒ entropy↑ (noise/mask 추가) | t↑ ⇒ I(z_t; h₀)↓ (정보 제거) |
| 정보 손실 메커니즘 | random (noise 또는 mask) | learned (어떤 정보를 잃을지 학습) |
| 순방향 모델 학습 여부 | 학습 ✗ (고정 schedule) | 학습 ✓ (compression module이 학습됨) |

이 차이는 단순한 표현 차이가 아니다. LACE의 순방향 과정은 **encoder가 학습하는 deterministic mapping**이며, 이 때문에 reverse는 단순한 denoising이 아니라 *학습된 압축의 역연산*을 풀어야 한다.

### D2. 시간축 t의 정의가 "정보율 (nats/token)"이다.

| 비교 항목 | 선행연구 | LACE |
|---|---|---|
| t의 단위 | variance, log-SNR, mask ratio | nats/token (정보이론적 단위) |
| t와 latent dimension의 관계 | 무관 (차원 고정) | 연동 (N_t는 t의 함수) |
| t의 측정 방법 | schedule에 의해 정의됨 | MINE, linear probing, reconstruction triangulation |

t를 정보율로 정의하면 *서로 다른 순방향 과정을 같은 척도로 비교*할 수 있게 된다. 이는 §9.3.1의 information rate 측정 프로토콜로 검증한다.

## 5. 인접 위험에 대한 선제적 반론

논문 review에서 제기될 가능성이 높은 4가지 반론을 명시하고 대응한다.

### 위험 5.1 — "Plaid의 log-SNR가 이미 information rate 아닌가?"

- **반론 요지**: Plaid의 log-SNR는 *추가된 noise의 channel capacity*를 측정한다. 이는 "원본 정보가 얼마나 남아있는가"의 *간접 추정*이다.
- **LACE의 차별점**: latent의 *bandwidth 자체*를 단계적으로 줄인다. 즉 t는 추가 noise의 양이 아니라 *유지된 정보의 양*을 직접 측정한다. log-SNR는 representation 차원이 변하지 않는 가정 하에서만 의미 있지만, LACE는 차원 자체가 변한다.
- **검증 실험**: §9.3.2 V2 (Latent Gaussian) vs V5 (LACE) 비교에서 동일 information rate budget 하에 어느 쪽이 더 좋은 reconstruction/generation을 보이는지 확인.

### 위험 5.2 — "LD4LG에 latent pooling만 추가하면 동일하지 않은가?"

- **반론 요지**: LD4LG의 pretrained encoder에 attention pooling을 추가하면 단계적 압축처럼 보일 수 있다.
- **LACE의 차별점**:
  1. LD4LG는 순방향 과정에서 차원을 줄이지 않는다 — pooling을 추가해도 *학습 시* diffusion은 여전히 고정 차원에서 일어난다.
  2. LACE는 정보율 budget이 *training loss의 일부 (L_info)*다. 단순 pooling은 정보율을 보장하지 않는다.
- **검증 실험**: §9.3.2 V4 (latent pooling only) vs V5 (pooling + rate constraint)가 결정적 ablation. V4 ≈ V5라면 rate constraint는 불필요한 것이고, V5 > V4라면 rate constraint가 본 연구의 핵심 기여임이 입증된다.

### 위험 5.3 — "Optimus/DELLA와 무엇이 다른가?"

- **반론 요지**: hierarchical VAE도 단계적 latent를 가진다.
- **LACE의 차별점**:
  1. Hierarchical VAE는 *generative reverse trajectory*가 없다. z를 한 번 sampling하고 decode할 뿐이다.
  2. 시간축이 없다 — 중간 단계에서 generation을 멈추거나 조건을 바꿔 다시 생성하는 controllability가 없다.
  3. LACE의 reverse는 z_T → z_{T-1} → ... → h_0 → text의 iterative process이며, 각 단계에서 conditional generation, classifier guidance, refinement가 가능하다.

### 위험 5.4 — "Funnel/Perceiver의 단계적 압축과 동일하지 않은가?"

- **반론 요지**: Funnel transformer도 sequence를 단계적으로 줄인다.
- **LACE의 차별점**:
  1. Funnel은 *encoder*다. 학습은 standard supervised objective (classification, MLM)로 이루어지며 generative model이 아니다.
  2. Reverse expansion이 학습 objective에 없으므로 generation에 사용할 수 없다.
  3. LACE는 encoder + compressor + expander + renderer를 *jointly* 학습하여 압축 표현으로부터 텍스트를 생성한다.

## 6. LACE의 위치

위 비교를 종합하면 LACE는 다음 교집합 영역의 **빈 칸**을 채운다.

```
                    생성형 모델 (Reverse process 있음)
                           |
                           |
          ┌────────────────┼────────────────┐
          |                |                |
   시간축 ✓ (Diffusion)  LACE       시간축 ✗
   - LLaDA              ← 여기          - Optimus
   - Diffusion-LM                       - DELLA
   - Plaid, LD4LG                       - Funnel (✗ generative)
          |                |                |
   압축 ✗               압축 ✓               압축 ✓
   고정 차원             가변 차원            정적 계층
```

LACE는 **diffusion의 시간축**, **hierarchical VAE의 단계적 압축**, **명시적 정보율 제어**를 모두 가지는 첫 번째 모델이다.
