00 · Tokens

Design System v2

Mobbin의 --neutral-N 스케일과 saturated primary hues를 차용하되, 포트폴리오 맥락에 맞게 타이포 스케일과 서브 컬러(yellow / purple / pink)를 재조정했습니다. 모든 토큰은 :root에 HSL 세트로 선언돼 있고, data-theme="dark"로 다크 모드가 토글됩니다.

06 · Portfolio mapping

이 토큰이 실제 포트폴리오에서 어떻게 쓰이는지

실제 design/index.html에 적용할 때의 매핑입니다. 섹션 헤더 · 필터바 · 그리드 카드 · 타입 뱃지만으로 기존 v1/v2의 editorial numbering + serif vocabulary를 완전히 대체합니다.

Hero
Browse my work
the way you browse products.

Inter Tight 800 · display. 세리프 이탤릭 전부 제거. 강조는 em (yellow-10 background) 한 장치로 통일.

Nav

sticky topnav + 좌측 로고/네비 + 중앙 검색 바 + 우측 테마토글/CTA. Mobbin 상단 layout 그대로 차용.

Filterbar

hero 바로 아래에 sticky. All / Projects / Research / Papers / Ideas / Labs + 토픽 칩. 실제 filtering은 prefers-js로 선택적 구현.

Grid

프로젝트·연구·논문·아이디어를 하나의 그리드에 섞어 배치. 타입은 카드 위 뱃지로만 구분. 섹션 나누지 않고 "브라우즈" 느낌 유지.

Color strategy

페이지 전체는 거의 뉴트럴. 색은 카드 cover 안에서만 폭발하게. 결과적으로 그리드는 무지개, chrome은 흑백.

Dark mode

data-theme 토글로 즉시 반전. 뉴트럴 스케일만 뒤집고 brand hue는 유지.
