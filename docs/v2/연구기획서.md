# 연구계획서 초안

## **Compression, not Corruption: Semantic Information-Rate Schedules for Diffusion Language Modeling**

---

## 1. 연구 배경

최근 Diffusion Language Model, 즉 DLM은 autoregressive language model의 대안으로 주목받고 있다. 기존 DLM은 보통 문장을 점진적으로 손상시키는 forward process를 사용한다. 예를 들어 일부 token을 `[MASK]`로 바꾸거나, token을 random replacement하거나, latent representation에 noise를 추가한다. 이후 reverse process는 손상된 문장 또는 표현으로부터 원래 문장이나 token을 복원하도록 학습된다.

그러나 언어는 이미지와 다르다. 이미지는 연속적인 pixel 공간에 Gaussian noise를 더하는 방식이 비교적 자연스럽지만, 언어는 discrete token, 문법 구조, 의미 중심성, 핵심 단어와 부가 단어의 계층성을 가진다. 따라서 무작위 corruption은 언어적 의미 구조를 반영하지 못할 수 있다.

본 연구는 이 문제의식에서 출발한다.

> **언어 diffusion의 forward process는 corruption이 아니라 semantic compression이어야 하지 않을까?**

즉, diffusion time `t`를 noise severity가 아니라 **semantic information rate**로 재해석한다. 시간이 지날수록 문장은 무작위로 망가지는 것이 아니라, 덜 중요한 token부터 제거되어 점점 핵심 의미만 남는 semantic skeleton으로 압축된다. Reverse process는 이 semantic skeleton에서 출발해 점점 더 풍부한 문장을 생성하는 coarse-to-fine expansion 과정으로 학습된다.

---

## 2. 연구 문제

본 연구의 핵심 질문은 다음과 같다.

> **Diffusion Language Modeling의 forward process를 random corruption이 아니라 importance-guided semantic compression process로 정의할 수 있는가?**

이를 세부적으로 나누면 다음과 같다.

### RQ1. Semantic compression forward process는 언어 생성에 적합한 diffusion trajectory를 만들 수 있는가?

기존 masked DLM은 token을 무작위로 mask하거나 일정한 확률 schedule에 따라 손상시킨다. 본 연구는 token importance를 계산하고, 중요도가 낮은 token부터 순차적으로 mask하여 핵심 token이 마지막까지 남는 forward trajectory를 만든다.

### RQ2. Terminal state는 실제로 semantic skeleton으로 작동하는가?

Forward process의 마지막 상태 `x_T`는 단순히 많이 손상된 문장이 아니라, 원문의 핵심 의미를 담은 semantic skeleton이어야 한다.

### RQ3. Reverse process는 skeleton에서 full sentence로 확장하는 coarse-to-fine generation을 학습할 수 있는가?

Reverse model은 단순 denoising이 아니라, 핵심 token에서 출발해 문장 구조, 수식어, 기능어, 세부 정보를 점진적으로 추가하는 expansion model로 작동해야 한다.

### RQ4. Importance-guided compression은 random masking, Gaussian/noise corruption, anchor prediction 방식보다 generation에 유리한가?

가장 가까운 선행연구인 anchor-based DLM과의 차이를 검증하기 위해, “중요 token을 예측해서 조건으로 주는 방식”과 “중요 token을 forward process에서 마지막까지 보존하는 방식”을 비교한다.

---

## 3. 핵심 가설

본 연구의 중심 가설은 다음과 같다.

> **중요도가 낮은 token부터 제거하고 핵심 token을 마지막까지 보존하는 semantic compression forward process는, random corruption 기반 forward process보다 더 언어적으로 자연스러운 reverse generation trajectory를 제공한다.**

이 가설은 세 가지 하위 가설로 나뉜다.

### H1. Semantic preservation

Importance-guided compression은 random masking보다 압축 상태에서도 원문의 핵심 의미를 더 잘 보존한다.

### H2. Reverse expansion stability

Semantic skeleton에서 출발한 reverse process는 무작위로 손상된 문장에서 출발하는 reverse process보다 더 안정적인 복원 및 생성 경로를 학습한다.

### H3. Generation quality

Compression-based reverse process는 token reconstruction, constrained generation, open-ended generation에서 random corruption baseline보다 더 나은 의미 일관성과 문장 품질을 보인다.

---

## 4. 기존 연구와의 차별성

본 연구와 가장 가까운 문헌은 중요 token 또는 anchor token을 활용하는 Diffusion Language Model 계열이다. 특히 Anchored Diffusion Language Model 계열은 중요한 token이 early masking되면 denoising이 어려워진다는 문제를 제기하고, anchor network를 통해 중요한 token distribution을 예측한다.

그러나 본 연구는 이들과 다르다.

| 구분                 | 기존 anchor-based DLM                    | 본 연구                                      |
| ------------------ | -------------------------------------- | ----------------------------------------- |
| 중요 token의 역할       | reverse denoising을 돕는 auxiliary anchor | forward process의 compression order를 정의    |
| forward process    | 기본 random/masked corruption 유지         | 중요도 낮은 token부터 제거하는 semantic compression  |
| terminal state     | heavily masked/noisy state             | 핵심 token skeleton                         |
| reverse process    | anchor-conditioned denoising           | skeleton-to-text coarse-to-fine expansion |
| diffusion time `t` | corruption severity                    | semantic information rate                 |

본 연구의 핵심 차별점은 다음 문장으로 요약할 수 있다.

> **Important tokens are not auxiliary anchors; they are the terminal state of the forward diffusion process.**

즉, 중요한 token은 reverse process를 돕기 위해 추가로 예측되는 보조 신호가 아니라, forward diffusion이 도달해야 할 최종 compressed state 자체다.

## 5. 방법론

## 5.1 전체 구조

전체 학습 흐름은 다음과 같다.

```text id="7eu38v"
Original sentence x_0
→ importance scoring
→ importance-ordered masking/compression
→ semantic skeleton x_T
→ reverse expansion model
→ reconstructed/generated sentence x_0_hat
```

Forward process는 학습 데이터로부터 여러 단계의 compressed state를 만든다.

```text id="7pay8f"
x_0 → x_1 → x_2 → ... → x_T
```

Reverse process는 이를 거꾸로 복원한다.

```text id="c0w4l6"
x_T → x_{T-1} → ... → x_1 → x_0
```

---

## 5.2 Token importance scoring

문장 `x = (x_1, x_2, ..., x_n)`에 대해 각 token의 중요도 score를 계산한다.

```text id="5bvgm0"
s_i = f_\phi(x_i, x)
```

가능한 importance scorer는 다음과 같다.

| 방식                    | 설명                                   | 장점             | 위험                        |
| --------------------- | ------------------------------------ | -------------- | ------------------------- |
| Attention received    | 다른 token들이 해당 token을 얼마나 참조하는지       | 구현 쉬움          | attention faithfulness 논쟁 |
| Gradient saliency     | loss에 대한 token embedding gradient 크기 | task-sensitive | 계산 비용 큼                   |
| PMI / informativeness | token의 정보량 기반                        | 비지도 가능         | local statistic에 치우침      |
| POS / dependency      | 명사, 동사, 주어, 목적어 등 구조 기반              | 해석 가능          | rule-based 한계             |
| Learned scorer        | 중요도 예측 모델 학습                         | 유연함            | leakage/collapse 위험       |
| Hybrid scorer         | 여러 점수 결합                             | 안정적            | 설계 복잡                     |

초기 실험에서는 다음 세 가지를 우선 비교한다.

1. Frequency/PMI 기반 중요도
2. Attention received 기반 중요도
3. Learned importance scorer

---

## 5.3 Importance-ordered forward compression

중요도 score `s_i`를 기준으로 token을 정렬한다.

```text id="7a4j5h"
π = argsort(s_i)
```

여기서 `π(1)`은 가장 덜 중요한 token이고, `π(n)`은 가장 중요한 token이다.

시간 `t`에서 제거할 token 집합은 다음과 같이 정의한다.

```text id="qogdjn"
M_t = {π(1), π(2), ..., π(k_t)}
```

따라서 forward process는 다음과 같다.

```text id="1ar3zu"
q(x_t | x_0) = Mask(x_0, M_t)
```

즉, `t`가 증가할수록 중요도가 낮은 token부터 masking되고, 중요한 token은 마지막까지 남는다.

예시:

```text id="9e21ou"
x_0: 작은 고양이가 부엌에서 신선한 생선을 조심스럽게 먹었다
x_1: 고양이가 부엌에서 신선한 생선을 먹었다
x_2: 고양이가 생선을 먹었다
x_3: 고양이 생선 먹다
x_T: 고양이 생선
```

여기서 `x_T`는 semantic skeleton이다.

---

## 5.4 Reverse expansion model

Reverse model은 다음 조건부 분포를 학습한다.

```text id="87cdjk"
p_\theta(x_{t-1} | x_t, t)
```

전체 생성 확률은 다음과 같다.

```text id="nnw6yh"
p_\theta(x_0 | x_T) = ∏_{t=T}^{1} p_\theta(x_{t-1} | x_t, t)
```

모델 구조는 초기에는 Transformer encoder-decoder 또는 masked LM 기반 denoiser를 사용한다. 추후에는 insertion-based decoder 또는 non-autoregressive decoder를 고려한다.

Reverse process는 단순히 `[MASK]`를 채우는 것이 아니라, semantic skeleton에서 더 풍부한 문장으로 확장하는 과정으로 정의한다.

---

## 5.5 학습 objective

초기 objective는 token reconstruction loss를 사용한다.

```text id="7v9nj5"
L_token = - log p_\theta(x_{t-1} | x_t, t)
```

추가로 semantic preservation objective를 둘 수 있다.

```text id="u9iojp"
L = L_token + λ_sem L_sem + λ_order L_order
```

여기서:

* `L_token`: token reconstruction loss
* `L_sem`: 원문과 생성문 embedding similarity 유지
* `L_order`: 중요도 순서가 reverse generation에 반영되는지 유도하는 보조 loss

만약 latent hidden representation을 사용하는 경우에는 다음 objective를 사용할 수 있다.

```text id="x1vlwt"
L = L_hidden + λ_cos L_cos + λ_token L_token
```

하지만 본 연구의 최종 목표는 hidden reconstruction이 아니라 token/generation 성능이므로, `L_token`과 generation metric을 중심으로 둔다.

## 8. 예상 결과와 해석

## 가능한 긍정 결과

### 결과 A. Semantic compression이 random masking보다 의미 보존이 좋음

이는 본 연구의 기본 가설을 지지한다.

### 결과 B. Reverse expansion에서 skeleton 기반 입력이 더 안정적임

이는 compression trajectory가 reverse learning에 도움이 된다는 증거다.

### 결과 C. ADLM-style anchor prediction보다 importance-ordered forward가 좋음

이 경우 novelty가 강해진다.

주장 가능 문장:

> Token importance should define the forward diffusion trajectory, rather than merely serving as an auxiliary reverse-time anchor.

### 결과 D. Hybrid 방식이 가장 좋음

즉, importance-ordered forward와 anchor prediction을 함께 쓰는 것이 가장 좋다면, 다음 주장도 가능하다.

> Semantic compression and anchor prediction are complementary: compression defines the state trajectory, while anchor prediction improves local denoising.

---

## 가능한 부정 결과

### 결과 A. Random masking과 차이가 없음

이 경우 importance schedule이 실제로 reverse learning에 도움이 되지 않는다는 뜻이다.

### 결과 B. ADLM-style anchor prediction이 훨씬 좋음

이 경우 forward trajectory를 바꾸는 것보다 reverse conditioning이 더 중요하다는 결론이 나온다.

### 결과 C. Skeleton은 의미를 보존하지만 generation 품질은 개선하지 못함

이 경우 bottleneck은 forward process가 아니라 decoder/reverse objective일 가능성이 높다.

## 9. 연구의 기대 기여

본 연구의 기여는 다음과 같이 정리할 수 있다.

### Contribution 1. Diffusion time의 재해석

기존 DLM에서 diffusion time은 corruption severity로 해석된다. 본 연구는 이를 semantic information rate로 재해석한다.

### Contribution 2. Importance-ordered semantic compression forward process

중요도 낮은 token부터 제거하고 핵심 token을 마지막까지 보존하는 forward process를 제안한다.

### Contribution 3. Skeleton-to-text reverse expansion

Reverse process를 denoising이 아니라 semantic skeleton에서 full sentence로 확장하는 coarse-to-fine generation으로 정식화한다.

### Contribution 4. Anchor-based DLM과의 구조적 차별화

중요 token을 auxiliary anchor로 예측하는 것이 아니라, terminal compressed state로 보존하는 접근을 제안한다.

### Contribution 5. Forward schedule의 언어적 자연성 검증

무작위 corruption보다 언어의 의미 계층성에 맞는 forward trajectory가 generation에 도움이 되는지 실험적으로 검증한다.

## 10. 연구의 위험 요소와 대응

| 위험 요소                                | 설명                        | 대응                                                         |
| ------------------------------------ | ------------------------- | ---------------------------------------------------------- |
| Attention score가 중요도를 잘 반영하지 않을 수 있음 | attention faithfulness 문제 | PMI, gradient, learned scorer, oracle과 비교                  |

| Skeleton이 너무 sparse할 수 있음            | reverse generation이 어려움   | compression level schedule 조절                              |
| Reverse model이 skeleton을 무시할 수 있음    | language prior만으로 생성      | skeleton swap/ablation control                             |
| Open-ended generation 평가가 불안정        | 실패 원인 분리 어려움              | constrained generation부터 단계적 평가                            |
| 중요도 scorer가 leakage를 일으킬 수 있음        | 원문 정보를 과도하게 사용            | scorer 학습 조건과 inference 조건 분리                              |

# 최종 요약

본 연구는 기존 Diffusion Language Model의 forward process가 언어에 적합하지 않을 수 있다는 문제의식에서 출발한다. 기존 방식은 token을 무작위로 손상시키지만, 본 연구는 언어의 의미 구조를 반영하여 중요도가 낮은 token부터 제거하고 핵심 token을 마지막까지 보존하는 **semantic compression forward process**를 제안한다.

이때 diffusion time은 corruption severity가 아니라 **semantic information rate**로 해석된다. Reverse process는 semantic skeleton에서 출발해 full sentence를 생성하는 **coarse-to-fine expansion process**로 학습된다.

가장 중요한 차별점은 다음이다.

> 중요한 token은 reverse denoising을 돕는 auxiliary anchor가 아니라, forward diffusion이 도달하는 terminal compressed state다.

따라서 본 연구의 핵심 검증은 다음 질문에 있다.

> **중요도 기반 semantic compression trajectory가 random corruption이나 anchor prediction보다 더 좋은 generation-capable reverse process를 학습시키는가?**
